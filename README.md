Та сама гра з Siemens C35/C45: крани скидають ящики, а ти штовхаєш їх і збираєш ряди, поки тебе не привалило. 

Оригінальна графіка, звуки C45, палітра з жовтим підсвічуванням Siemens або чорно-біла. 

За основу був узятий фанатський ремейк під Flipper Zero від Negenii (http://github.com/Negenii/flipper-stack-attack)

### Як запустити: 

Поклади stack_attack.bin на SD-карту і відкрий у KeiraOS.

### Подяки

- Оригінальна гра: Siemens.
- Ремейк для Flipper Zero, усі правила, графіка та звуки: Євген Угренінов ([@Negenii](https://github.com/Negenii)).
- Консоль Лілка та SDK: спільнота Лілки ([github.com/lilka-dev](https://github.com/lilka-dev)).
